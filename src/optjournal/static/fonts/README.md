# Fonts

Geist and Geist Mono, by Vercel with basement.studio, under the SIL Open Font
License 1.1 (`OFL.txt`, which must travel with these files).

Taken unmodified from Vercel's published npm package `geist@1.7.2`
(`dist/fonts/geist-sans/Geist-Variable.woff2`,
`dist/fonts/geist-mono/GeistMono-Variable.woff2`), whose tarball matched the
registry's sha512 integrity hash when fetched on 2026-09-28. To update, fetch a
newer tarball from `https://registry.npmjs.org/geist`, verify its `integrity`
field the same way, and replace both files and the license together.

Not taken from any other application's bundle. These are the variable builds:
one file per family covers every weight this page uses, which is why there are
two files rather than six.
